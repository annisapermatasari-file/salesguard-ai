Data & Backup

Data tersimpan di cloud untuk workspace demo dan bisa dibuka dari perangkat lain. Jika server tidak tersedia, data disimpan sementara di perangkat ini. Ekspor JSON untuk cadangan.

Tentang SalesGuard AI

Sales control tower untuk menjawab masalah umum tim sales: data customer tersebar, follow-up terlambat, pipeline tidak terkontrol, laporan manual, approval lewat chat, dan data hilang ketika sales berganti.

Data tersinkron ke Cloudflare D1 per workspace. Buka dari perangkat lain dengan alamat yang sama dan ?workspace=demo.
Alur utama

Lead → Customer → Deal → Pipeline → Follow-Up → Approval → Closing.
